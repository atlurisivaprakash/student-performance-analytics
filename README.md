Student Performance Analytics System

1. Project Title

Student Performance Analytics System

2. Objective

The objective of this project is to build a Python-based Student Performance Analytics System that reads student data, processes it, and analyzes student performance using Python, NumPy, and Pandas.

The system calculates total marks, average marks, grades, pass/fail status, subject-wise performance, overall class average, and identifies top-performing students.

3. Technologies Used

- Python
- NumPy
- Pandas
- CSV Dataset

4. Dataset Description

The project uses a CSV dataset containing 20 student records.

The dataset contains the following fields:

- Student ID
- Name
- Department
- Python Marks
- Maths Marks
- DBMS Marks
- Attendance

5. Implementation

The project reads the student dataset using Pandas.

NumPy is used for numerical calculations such as total marks, averages, and subject-wise performance.

Functions are used to calculate grades and determine whether a student has passed or failed.

A loop is used to perform subject-wise performance analysis.

The system also identifies the highest-performing student, lowest-performing student, overall class average, number of passed students, number of failed students, and top five performers.

6. Key Features

- Student data loading using Pandas
- Total marks calculation
- Average marks calculation
- Grade assignment
- Pass/fail identification
- Highest and lowest performance analysis
- Overall class average
- Subject-wise performance analysis
- Top five performers
